# Payment Rail

Public idea vault. Not a licensed payment service. Not a bank.

**Non videri sed esse.** Do not appear to hold money. Be the pipe.

## The idea

A Canadian transaction overlay.

The institution holds the CAD. The overlay is a cash account UI, a connector catalog, an instant hold API, and a daily recon file that must match the institution's books or the send does not exist.

Users get an intermediary for transfers, not a place to store wealth. Same hole PayPal filled. Different rails. Different decade.

## Dual costume

We do not pick the legal seat in a vacuum. We offer both. The institution chooses.

- **Seat A.** Listed agent of a registered payment service provider. Work stays inside their mandate. Their agent list. Their safeguarding model.
- **Seat B.** Overlay in front of a bank or trust. They hold the CAD. If the law says the agent of an excluded institution must register as a PSP, we register.

Product does not change between seats.

## What we are not

- Not a vault.
- Not a clone of a phone secure element.
- Not a card chip copy.
- Not a way around KYC.
- Not OSFI. Not a Schedule I bank.

Agentic connectors are a later tier on the same freeze and the same identification rules. Flexibility after control.

## Core locks

| Layer | Rule |
| --- | --- |
| Money | Institution holds CAD. Overlay mirrors. Ghost money is forbidden. |
| Control | Institution can freeze an account or a set of accounts the same second. No queue. |
| Recon | Daily match to sponsor books is the same system as the audit trail. |
| Load | Connectors and onboarding cache. Direct debit later, only when the sponsor's PAD program exists. |
| Identity | Fast KYC. Ten stages. Tier gates. FINTRAC-shaped. |
| Fees | Interac as marketing cost if the sponsor will carry it. Monetize elsewhere. |
| Entity | Numbered Alberta corporation first. Brand is a trade name later. |
